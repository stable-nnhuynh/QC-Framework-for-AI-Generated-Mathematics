# Standard Operating Procedure: AI Mathematics Solution Audit & Correction

**Document ID:** SOP-MATHGPT-001
**Version:** 1.0
**Classification:** Internal — Expert Review Team
**Author:** Huynh — Mathematics Content Specialist
**Effective Date:** 2024
**Applicable Scope:** All AI-generated solutions for University-Level Mathematics (OpenStax-aligned)

---

## 1. Purpose

This document establishes a standardized, repeatable procedure for Global Experts to **verify**, **optimize**, and **score** AI-generated mathematics solutions. The goal is to ensure every published solution meets the quality bar required for student-facing educational content.

---

## 2. Definitions

| Term | Definition |
|---|---|
| **AI Raw Output** | The unedited solution generated by the MathGPT model. |
| **Expert** | A qualified mathematics reviewer (MS/PhD level or equivalent). |
| **Audit** | The systematic review process defined in this SOP. |
| **Error Code** | A unique identifier from the Error Taxonomy (ref: `Error_Taxonomy_Analysis.csv`). |
| **Golden Solution** | The final, Expert-approved version that serves as ground truth. |
| **Rubric Score** | A numerical score (0–100) assigned during Final Scoring. |

---

## 3. Prerequisites

Before beginning an audit, the Expert must have access to:

- [ ] The AI Raw Output (problem statement + generated solution)
- [ ] The Error Taxonomy reference table (`ERR-XXX-YYY` codes)
- [ ] The LaTeX Coding Standard (`LaTeX_Coding_Standard.md`)
- [ ] The relevant OpenStax textbook chapter for cross-referencing
- [ ] A LaTeX renderer (KaTeX/MathJax preview environment)

---

## 4. Procedure

### Phase 1: Verification (Mathematical Correctness)

**Objective:** Determine whether the AI solution is mathematically correct.

#### Checklist:

- [ ] **1.1 Problem Restatement Check**
  - Does the AI correctly restate or interpret the problem?
  - Are all given conditions and constraints accurately captured?
  - Flag: `ERR-CNT-001` if a theorem or condition is misquoted.

- [ ] **1.2 Methodology Validation**
  - Is the chosen solution method appropriate for the problem type and course level?
  - Does the method align with the approach taught in the relevant OpenStax chapter?
  - Flag: `ERR-CNT-002` if the method is applied outside its valid domain.
  - Flag: `ERR-PED-003` if the difficulty level is miscalibrated.

- [ ] **1.3 Step-by-Step Logic Trace**
  - Independently re-derive the solution from scratch.
  - Compare each AI step against your derivation.
  - For each step, verify:
    - [ ] The logical inference is valid (no `ERR-LOG-002`).
    - [ ] No steps are fabricated or hallucinated (`ERR-LOG-001`).
    - [ ] No critical steps are omitted (`ERR-LOG-005`).
    - [ ] The converse of a theorem is not incorrectly applied (`ERR-LOG-004`).
    - [ ] No circular reasoning is present (`ERR-LOG-003`).

- [ ] **1.4 Computational Verification**
  - Recompute all arithmetic and algebraic manipulations.
  - For matrix problems: verify all matrix operations entry-by-entry.
  - For calculus problems: verify derivatives, integrals, and limits independently.
  - Flag: `ERR-CMP-001` through `ERR-CMP-005` as applicable.

- [ ] **1.5 Answer Verification**
  - Substitute the final answer back into the original problem.
  - Confirm the answer satisfies all stated conditions.
  - For eigenvalue problems: verify $A\mathbf{v} = \lambda\mathbf{v}$ explicitly.
  - For optimization: verify second-derivative or boundary conditions.
  - Flag: `ERR-PED-004` if the AI did not perform its own verification.

**Phase 1 Gate:** If any `P0 - Immediate` error is found, the solution is marked **FAIL** and must be fully rewritten in Phase 2.

---

### Phase 2: Optimization (Solution Quality & Formatting)

**Objective:** Refine the solution for clarity, pedagogy, and formatting compliance.

#### Checklist:

- [ ] **2.1 Pedagogical Review**
  - Is every step justified with sufficient explanation for the target audience?
  - Are there any "by inspection" or "it is obvious" claims that require elaboration?
  - Flag: `ERR-PED-001` for insufficient justification.
  - Flag: `ERR-PED-002` if a simpler method exists and is more appropriate.

- [ ] **2.2 Solution Structure Compliance**
  - Does the solution follow the standard template?
    ```
    Problem → Step 1 → Step 2 → ... → Step N → Verification → Final Answer
    ```
  - Is the final answer enclosed in `\boxed{}`?
  - Flag: `ERR-FMT-003` for structural issues.

- [ ] **2.3 LaTeX Quality Assurance**
  - All formulas render correctly in the preview environment.
  - Display mode is used for complex expressions (`ERR-FMT-002`).
  - Equation alignment uses `aligned` environment (`ERR-FMT-001`).
  - All operators use `\operatorname{}` or built-in commands.
  - Matrix notation follows the LaTeX Coding Standard.
  - Flag: `ERR-NTN-001` through `ERR-NTN-004` as applicable.

- [ ] **2.4 Notation Consistency Sweep**
  - Scan the entire solution for notation inconsistencies.
  - Verify vector notation (bold lowercase: $\mathbf{v}$) is consistent throughout.
  - Verify matrix notation (uppercase italic: $A$) is consistent throughout.
  - Verify eigenvalue notation ($\lambda_1, \lambda_2, \ldots$) is consistent.
  - Flag: `ERR-NTN-002` for mismatches, `ERR-NTN-003` for symbol abuse.

- [ ] **2.5 Expert Annotation**
  - For every correction made, insert an audit comment:
    ```
    <!-- AUDIT: ERR-XXX-YYY | Description of the fix applied -->
    ```
  - Record all flagged errors in the session log for analytics.

### Phase 3: Final Scoring (Rubric-Based Assessment)

**Objective:** Assign a quantitative quality score to the AI Raw Output.

#### Scoring Rubric:

| Criterion | Weight | Score Range | Description |
|---|---|---|---|
| **Mathematical Correctness** | 40% | 0–40 | All computations and logical steps are valid. |
| **Completeness** | 20% | 0–20 | No steps are skipped; verification is present. |
| **Pedagogical Clarity** | 20% | 0–20 | Explanations are appropriate for the target level. |
| **LaTeX & Formatting** | 10% | 0–10 | Compliant with LaTeX Coding Standard. |
| **Notation Consistency** | 10% | 0–10 | Notation is uniform and standard throughout. |

#### Scoring Procedure:

- [ ] **3.1** Score each criterion independently using the ranges above.
- [ ] **3.2** Compute the total Rubric Score (0–100).
- [ ] **3.3** Assign a quality tier:

| Tier | Score Range | Action |
|---|---|---|
| **Excellent** | 90–100 | Approve for publication. Minor polish only. |
| **Good** | 75–89 | Approve with mandatory revisions noted. |
| **Needs Improvement** | 50–74 | Return to AI pipeline with detailed feedback. |
| **Reject** | 0–49 | Full rewrite required by Expert. |

- [ ] **3.4** Complete the Audit Summary:

```

│           AUDIT SUMMARY TEMPLATE                │
├─────────────────────────────────────────────────┤
│ Problem ID:         ________________________    │
│ Expert Name:        ________________________    │
│ Date:               ________________________    │
│ Rubric Score:       _____ / 100                 │
│ Quality Tier:       ________________________    │
│ Errors Found:       ________________________    │
│ Error Codes:        ________________________    │
│ Disposition:        [ ] Approve                 │
│                     [ ] Revise                  │
│                     [ ] Reject                  │
│ Comments:           ________________________    │
└─────────────────────────────────────────────────┘
```

- [ ] **3.5** Submit the Golden Solution and Audit Summary to the Operations pipeline.

## 5. Escalation Protocol

| Scenario | Action |
|---|---|
| Expert is unsure about the correctness of a step | Escalate to a second Expert for peer review. |
| AI consistently produces the same error type | File a model feedback report with the Engineering team. |
| Problem statement itself contains an error | Flag to the Content Sourcing team for correction. |
| Disagreement between two Experts | Escalate to the Senior Content Lead for adjudication. |
